# Monocular-Obstruction-Estimation-with-SLAM-and-CNN

SLAM (simultaneous lacalization and mapping) is a widely researched algorithm in the field of robotics and self driving cars. We demonstrate the use of SLAM as a feature extraction technique for cleaning inputs to a convolutional neural network. The user wears a device with a single camera that processes the surroundings in real time and delivers auditory feedback of nearby obstructions to the user. The main components of this program are the SLAM algorithm, a convolutional neural network, and a text to speech engine. Shout out to [@geohot](https://github.com/geohot)
for original code in [twitchslam](https://github.com/geohot/twitchslam)
